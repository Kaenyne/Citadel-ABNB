# Dubai Tourism Data Analysis 🌴

Exploratory data analysis of **Dubai tourism and visitor datasets**.

## Overview

This repository analyzes Dubai's tourism data — visitor demographics, e-permits, e-ticketing, hotel performance, and overnight visitors — to uncover trends in the tourism industry.

## Datasets Included

- Divs / visitors demographic data
- E-permit and e-ticketing records (2022–2023)
- Hotel establishment performance
- Overnight visitors by region and source market
- Visitor counts by nationality

## Analysis

- `Dubai_Tourism.ipynb` — the main analysis notebook
- `Dubai Tourism Data Analysis.pdf` — full written report

## Tech Stack

- Python
- Pandas
- Jupyter Notebook
