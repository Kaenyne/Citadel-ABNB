# databnb-10city-zillow-panel: sample of estherkim99/cs1951a-final

**What it is.** Brown CS1951A (spring 2020) class project: raw Inside Airbnb `listings.csv` dumps for 8 US cities (Asheville, Austin, Boston, Chicago, Denver, Nashville, San Francisco, Seattle; 244 files, 2015-05 to 2020-02, ~5 GB committed in `data/airbnb/`), Dropbox links for 96 NYC/LA dumps, Zillow ZIP-month ZHVI (1996-04..2020-01) and ZRI (2010-09..2020-01) CSVs, and `housing.db` (SQLite, ~347k listing rows joined to Zillow by ZIP). Useful as an archive of pre-2023 Inside Airbnb dumps and an STR-vs-rent join.
**How pulled (2026-09-14).** `gh api .../git/trees/HEAD?recursive=1` for the inventory; `curl -sL` from raw.githubusercontent.com for README, `database_samples.txt`, `dropbox_links.txt`, the two preprocess scripts; `curl -r` byte-range heads (3 MB each) of the two Zillow CSVs and (2 MB each) of `asheville-2018-04-1.csv` and `sanfrancisco-2015-05.csv`; pandas trimmed the partial last line and, for the Airbnb files, kept 34-36 of ~95 columns.
**Caps.** ~8.1 MB written in total; `housing.db` (51.7 MB) and all other raw dumps were not pulled; Dropbox links not tested. No scraper, no login, no API key, airbnb.com not touched.
**Files.** `Zip_Zri_*_head.csv` (4,969 ZIP rows), `Zip_Zhvi_*_head.csv` (1,512 ZIP rows), `airbnb_*_head.csv` (361 and 675 listings), `database_samples.txt` (40-row samples of the 3 SQLite tables), `repo_README.md`, `dropbox_links.txt`, `preprocess_*.py`, `manifest.json`.
**Full dataset.** `git clone --depth 1 --filter=blob:none --sparse https://github.com/estherkim99/cs1951a-final` then `git sparse-checkout set data/airbnb` (~5 GB for all cities; check out only the cities needed), or fetch single dumps from `https://raw.githubusercontent.com/estherkim99/cs1951a-final/HEAD/data/airbnb/<city>-<YYYY-MM>.csv`. Austin/Seattle files are numbered, not dated: read `last_scraped`.
