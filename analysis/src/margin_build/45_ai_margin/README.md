# 45_ai_margin

Does AI rescue the Street's FY27 margin? What AI already does in the line build, what it has saved in the filings, a generous AI bull
case, the FY27 cost growth needed to hold the Street's margin and EBITDA on each revenue path, a FY27 grid (revenue path x cost case),
and the FY26 floor check. Reuses the 44_short_case_v2 copy of the 40_line_build engine unchanged.

Run from the repo root (exit 0):

    py -3.13 analysis/src/margin_build/45_ai_margin/run.py

Outputs: `data/processed/margin_build/45_ai_margin/`. Note: `docs/margin-build/notes/45_ai_margin.md`.
