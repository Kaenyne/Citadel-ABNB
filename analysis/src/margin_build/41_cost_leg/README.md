# 41_cost_leg

Is there a cost leg to the ABNB short? Street-implied cost growth against history, the cost-surprise record at every print (with
cost of revenue against LSEG's COGS consensus), where our FY27 cost excess sits, and FY27 cost-growth scenarios.

Run from the repo root (exit 0):

    py -3.13 analysis/src/margin_build/41_cost_leg/run.py

Outputs: `data/processed/margin_build/41_cost_leg/`. Note: `docs/margin-build/notes/41_cost_leg.md`.
Pre-registration: `docs/margin-build/notes/41_42_prereg.md`.
