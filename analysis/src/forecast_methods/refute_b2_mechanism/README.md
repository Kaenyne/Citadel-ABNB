# B2 mechanism refutation

Run from the repository root:

```text
.venv\Scripts\python.exe analysis/src/forecast_methods/refute_b2_mechanism/run.py
```

The script reads the fixed, metadata-corrected B2 result, its named guidance ledger, source vintage register and executable returns. It verifies the descriptive sentence and measures guide-convergence confounding without importing B2 statistic functions. Every run creates a new directory under `data/processed/forecast_methods/refute_b2_mechanism/`; no registry or scorer is touched. Regressions are retrospective diagnostic fits. Their coefficients are not traded or registered. All rows retain vendor and timestamp attribution in `audit_cells.csv`.
