Standing rules (the harness).
  1. Copy, never overwrite: new work in analysis/src/forecast_methods/<pkg>_v2/, outputs in data/processed/forecast_methods/<pkg>_v2/, notes in docs/revenue-forecast-strategy/05_backtests/; new registry method names; re-run harness/score.py after every registration.
  2. Point-in-time or it doesn't count: every consensus value carries vendor + timestamp (L0 vintage register); refit at guide dates; two windows W1 (1Q23+) and W2 (1Q24+); letter integers scored as ±0.5 intervals.
  3. Pass lines are written before the test runs; a failed test is published, not deleted.
  4. Baselines every object must beat: naive / AR(1), trailing-4, guide × (1 + cushion), the vintage-stamped Street, and — for GBV — the RNPL-corrected unearned-fees series.
  5. Nothing licensed on git (Bloomberg, Third Bridge, LSEG exports); manifests and SHA-256 only.

9If we can only do five things

  1. LSEG Workspace registration — unlocks point-in-time consensus history and makes Theses A and B real backtests instead of press-quote reconstructions. Human, 15 minutes.
  2. Thesis A backtest — decides whether the memo may claim an expectations edge. One agent-day, data on disk.
  3. Wire RNPL as a variable (u, L, re-based nights, λ chart, funds-payable score line) and resolve the FX-confound question — the bear engine of the memo. One agent-day plus Theo's review.
  4. September Inside Airbnb dumps → calendar pickup ≤ 90 days — the first alt-data object aimed at booked GBV. Theo, when the batch lands (mid/late Sep).
  5. NCLH kernel — the exhibit that turns an Airbnb observation into a method. One agent, 3–5 days, free data.
