# Integrating the GitHub catalogue finds into the ABNB stack

Date: 14 September 2026. Author: Krishang Surapaneni (compiled with Claude Code). Branch `krish/github-altdata-catalog`.
Source: seven lane specs plus one red-team pass over the 59 sampled sources (`docs/github-altdata/integration_plan_raw.json`
holds every field: feeds, transformation, coverage, pass line, full pull, blockers, effort, first command). This is a plan;
nothing here has been run, tested or registered.

## Bottom line

Of the 59 sampled sources, four are worth building before the 2 October memo and two more right after the 26 September card
freeze. Everything else is an exhibit, a cohort, a duplicate of something held, or parked. The rule that decides almost every
verdict is the team's own: a forecast input must be point-in-time and span both windows (W1 1Q23+, W2 1Q24+). Only two finds
pass that bar as *forecast* objects (DoltHub consensus vintages, EUROCONTROL daily flights); the pre-2023 Inside Airbnb
archives and the Booking.com releases are valuable for a different reason, which is testing the assumptions the existing
survivors already rest on. No pre-2023 archive adds a scored quarter: the harness scores 2021Q1 onward and ABNB has no y/y
before COVID.

## Ranked build list

### Before the 26 September freeze
1. **DoltHub consensus history → L0 register** (Theo, 1.5 d). Order of operations: T0 `dolt_log` query and three `AS OF` spot checks proving historical rows were never back-edited (if that fails, only the current snapshot may enter); dated backup of the register; rows built in `L0_dolthub_v2/` and appended through `consensus_history_loader.append()` with `role=pit_history`; **vendor string must not contain the substring "zacks"** (the red team found `l0.pit_consensus()` filters with `str.contains`, so "Zacks via DoltHub" would break the frozen `test_l0` Zacks test and leak the 2 Aug $4,540M row into the 6 Aug pre-guide lookup); the LSEG $4,610M hard-rule row stays; re-run `test_l0.py` and assert the first 161 rows are byte-identical to the backup. Pre-registered: T1 vendor equivalence on the 18 pre-guide cells (median |diff| ≤ 1.0%, sign agreement ≥ 16/18); T2 WP-A vendor swap (same verdict under both vendors = survivor); T3 WP-B FY revisions (an exactly-zero revision counts as a miss; 69% of weeks are unchanged). Then the paginated NCLH `sales_estimate` pull (≥ 60 s between calls; 403 after ~40).
2. **SEC companyfacts pulls for WP-E1 / WP-E2** (Jessie, 1 d for the data layer; E1 itself is 3–5 d and unclaimed). Not the edgartools library: the keyless `data.sec.gov` endpoints the repo already hits. NCLH `ContractWithCustomerLiabilityCurrent` 2017Q4–2Q26 (32 quarter-ends, 66 vintage rows, zero restatements > 0.5%), CCL/RCL as cross-checks, BKNG/EXPE `us-gaap:DeferredMerchantBookings`. The 2015–17 start needs the pre-ASC-606 tag; capacity days / occupancy / net yield need ~44 8-K parses; `targets.csv` is ABNB-only so E1 scores locally with `I0_protocol.walkforward` and files a harness change request.
3. **2023 reviews mirror → stays-index wedge test** (Krish + Theo, 1.5 d). One build, one folder, one note. Raw files under the gitignored store as `<market_key>_<dump_date>_reviews.csv.gz` so `E3` picks them up unchanged (110 of 116 keys match `market_geo.csv`; four need a manual map). NYC 132 MB and the 13-city subset 1.3 GB first; whole mirror 4.88 GB. If T1 fails, the stays index is re-registered under a new method name and `harness/score.py` re-run; if it passes, one sentence in the reviews-index note.
4. **daio EMEA flights** (Theo, 1 d). Eight yearly CSVs from raw.githubusercontent.com into `data/raw/eurocontrol_daio/` (gitignored, no licence file in the repo; a WP-O log line precedes any memo number). Pre-register: duplicate check against the held but ragged Eurostat `avia_paoc`; `min_fit=4` means W1 wf_n = 12, W2 = 10; fit from 1Q23 or use the "vs 2019" column for 2022 because the 2022 y/y is a reopening base effect. Country shares hand WP-X its EMEA destination weights.

## Rules that bind every build
Copy, never overwrite (`q3nowcast_v2/`, `govdata_v2/`, `L0_dolthub_v2/`, `altdata_v2/`, new method names in the registry). Raw files stay under `data/raw/` or `~/abnb_ia_capture/` with a manifest and SHA-256. The register is append-only with a dated backup first. Pre-register the pass line in the note before running; a failed test is written up. Never touch airbnb.com; no scraper of a third-party site runs without a WP-O line.
